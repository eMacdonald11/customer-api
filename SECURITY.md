# Security policy

## Reporting a vulnerability

Please report security issues through your organization’s standard disclosure process (for example, a security email alias or bug bounty program).

If you do not have an internal process yet, open a **private** security advisory in GitHub for this repository (if enabled) or contact the repository maintainers directly.

## Scope

This template is intended for **demo and local development**. Do not deploy it to production without a proper security review, hardening, and secrets management.
